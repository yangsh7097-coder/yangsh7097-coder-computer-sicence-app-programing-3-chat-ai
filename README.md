# 🔍 인구 집중 데이터 탐정 - 5학년 사회 수업 AI 프로그램

## 📚 수업 정보
- **단원**: 2. 우리나라 지역 탐구
- **차시**: 수도권 인구 집중의 원인 알아보기 (11/16차시)
- **대상**: 5학년 2반
- **교수·학습 모형**: 탐구학습 (직소 수업 기법)

## 🚀 실행 방법
```bash
# Python 3.12 환경에서
python -m streamlit run ai_making_with_streamlit.py
```

## ⚙️ 설정
`.streamlit/secrets.toml` 파일에 Google Gemini API 키를 입력하세요:
```toml
GOOGLE_API_KEY = "여러분의_API_키"
```

## 🎯 주요 기능
- 📊 지역별 인프라 데이터 인포그래픽 (지도 / 막대그래프 / 수도권 vs 비수도권 비율)
- 📝 가설 작성 및 저장 기능 (활동1)
- 👥 직소 모둠별 탐구 안내 (활동2)
- 🤖 AI 탐정 조수 챗봇 (Gemini 2.5 Flash)
- ✅ 결론 정리 및 AI 피드백 (활동3)
- 💾 탐구 기록 텍스트 파일 저장
